# Avatar assets

`thread-character.glb` is an original local sample character generated by `scripts/build-avatar.mjs`. It contains independent body and all eight wardrobe category groups, plus optional long hair. No remote assets or paid inference are used.

The shapes show categories and colors, not exact garment reconstructions or measured fit. Personal facial scans are imported locally at runtime and must preserve the actual scanned geometry and embedded texture. The standard body is not a reconstruction of the user's measurements.

Rebuild with `node scripts/build-avatar.mjs`. Validate with `node --test tests/avatarAsset.test.mjs` and the compiled avatar/scan tests. Native GL rendering and imported textures still need hardware acceptance.
